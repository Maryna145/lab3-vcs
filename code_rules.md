# Правила оформлення коду проєкту

1. Дотримуватися стандартів оформлення коду PEP 8 для Python.
2. Використовувати осмислені назви змінних і функцій англійською мовою.
3. Кожен новий модуль повинен супроводжуватися базовими тестами.
4. Уникати хардкоду конфігураційних параметрів у вихідному коді.
5. Додавати зрозумілі коментарі та опис до складних алгоритмів.
